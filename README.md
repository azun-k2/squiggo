# Squiggo

Support pages and privacy policy for **Squiggo**, a drawing-lesson and painting app for children (iPhone, iPad, Mac). Served by GitHub Pages at <https://azun-k2.github.io/squiggo/>.

Icons are regenerated from the app with `../_tools/make-site-icons.py` run in `../Squiggo`.
The store badges and the "More apps" grid are written by `../_tools/site-family.py apply`.
